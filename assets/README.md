# assets/

Put the default avatar and voice here (they are not shipped with the repository):

| file | used by | notes |
|---|---|---|
| `faces/default_teacher.jpg` | `video.default_face` | frontal face, good lighting, mouth visible; a short `.mp4` also works |
| `voices/default_teacher.wav` | `speech.default_voice` | ~5 s of clean speech, 16 kHz mono |
| `fonts/NotoSansSC-Regular.otf` | `slides.font_cjk` | optional; otherwise a system CJK font is used |

Only use faces and voices of people who have given explicit consent (or synthetic avatars).
